About Letterbot
What is Letterbot? −
Letterbot is a free, self-hosted AI email filter for Windows. It connects to your IMAP mailbox, analyzes incoming emails, determines priority and suggested action, and sends concise Telegram notifications — only for messages that need your attention. Everything runs locally on your computer, with no Letterbot cloud server.
Who is Letterbot for? +
Primarily for people whose inbox has become a task list: freelancers and sole traders who manage 20+ client relationships by email, developers and sysadmins who want a self-hosted open-source tool, and small businesses that need email intelligence without sending correspondence to foreign cloud services.
How is Letterbot different from Gmail AI or Superhuman? +
Gmail AI and Superhuman are cloud services — they process your email on their servers. Letterbot processes everything locally. Additionally, Letterbot is free, open source, and uses Telegram as the action surface instead of a dedicated email client. The combination of local + free + Telegram + multi-inbox routing exists nowhere else at zero cost.
Is Letterbot production-ready software? +
Yes for personal and small-business use. The codebase includes health checks, retry/backoff, SLA metrics, degraded-mode semantics, event model, and an observability dashboard. It is not suited for enterprise requirements like SAML/SSO, compliance certification, or centralized fleet management.
Privacy & data
Where does my email data go? +
Nowhere external. In the default mode, Letterbot reads email via IMAP from your mail server, processes it locally, and stores metadata in a SQLite database on your machine. No Letterbot servers exist to receive your data.
Does Letterbot require ChatGPT or any paid AI service? +
No. The default deterministic mode works without any external AI. LLM providers — GigaChat (Sber), OpenAI, Cloudflare Workers AI — are entirely optional. You activate one by setting llm_provider in the config file. Without it, the system runs in fully local mode.
If I enable an LLM, what exactly gets sent to it? +
Only the email body text (minimal context for classification). Attachment content, full raw email, sender address book, and history are not sent. You control which provider handles this under their own privacy policy.
What is stored in the local SQLite database? +
Metadata: sender, subject, date, detected email type, priority, priority source, extracted entities, snooze state, and analytics. Full email bodies and attachment content are processed in-memory and not persisted.
Does Letterbot have telemetry or analytics that phones home? +
No. Zero telemetry. The only outbound connections: your IMAP server, Telegram Bot API, and your chosen LLM provider (if configured). You can verify this in the open-source code on GitHub.
How do I delete all Letterbot data? +
Delete database.sqlite or the entire project folder. No cloud backups, no account deletion request needed — everything is on your machine.
Technical
Which email providers are supported? +
Any IMAP-compatible mailbox: Yandex.Mail (imap.yandex.ru), Mail.ru (imap.mail.ru), Gmail (imap.gmail.com with app password), corporate Exchange / Office 365, Outlook, FastMail, ProtonMail Bridge, and any IMAP server.
Can Letterbot run on an old or slow computer? +
Yes — this is one of the best Letterbot use cases. Tested on an Intel Celeron N4020 (2 cores, 1.1 GHz) with 3 GB RAM. An old laptop or spare desktop makes an excellent dedicated local email assistant.
Does Letterbot modify or delete my emails? +
No. Letterbot connects in IMAP read-only mode. It never deletes, moves, marks, flags, or modifies any email. Your inbox remains exactly as it was.
Can I connect multiple email accounts? +
Yes. Multi-Inbox Routing lets you connect unlimited IMAP mailboxes, routing each to a separate Telegram chat — work emails to one chat, personal to another, server alerts to a dedicated channel.
What happens if the internet goes down? +
Letterbot cannot sync IMAP or deliver Telegram messages without internet. It does not crash — it retries automatically on the next poll cycle. All local data remains intact.
Is there a local web interface? +
Yes. A read-only observability cockpit runs at http://127.0.0.1:8787. It shows: dashboard, email archive, AI decision trace with reason codes, system health, delivery SLA metrics (p90 latency, delivery rate, error rate), and sender relationship analytics. It does not connect to the internet.
Can Letterbot read PDF and Excel attachments? +
Yes. Letterbot extracts text from PDF and Excel (.xlsx) files without requiring Microsoft Office. Attachment content is factored into priority calculation — an invoice in a PDF can trigger 🔴 Urgent priority automatically.
What is the weekly digest? +
A summary sent every Monday: total emails processed, invoices detected (with amounts), contracts for review, overdue obligations, silent-partner risks (contacts who stopped replying), and pending replies you have not acted on.
Can Letterbot run on Raspberry Pi or Linux? +
Not officially supported, but technically possible if Python 3.10+ is available. Community members report success on Pi 4 with 4 GB RAM. Windows 10/11 is the only officially tested platform.
What if the LLM provider is unavailable? +
Letterbot automatically enters DEGRADED_NO_LLM mode and continues sending basic notifications using deterministic extraction. You receive a Telegram notification about the degraded state. Normal mode resumes automatically when the LLM recovers.
Features & behavior
How does priority work? How does Letterbot decide what is important? +
Letterbot analyzes sender history, email type (INVOICE, CONTRACT, SECURITY_ALERT, etc.), deadline keywords, attachment type, and frequency signals. Result: 🔴 Urgent (action today) / 🟡 Important (next few days) / 🔵 Low. Every decision includes a reason code like PRIO_INVOICE or PRIO_DEADLINE_1D — not a black box.
Does Letterbot learn from my corrections? +
Yes. When you tap a priority button in Telegram to override a decision, the system records it as a correction signal. Over time, Letterbot adapts — which senders you treat as urgent, which you consistently dismiss.
How does snooze with memory work? +
Tap a snooze button (2h, tomorrow, next week) in Telegram. At the scheduled time, Letterbot resurfaces the email with full context: original sender, subject, detected type, what action was suggested, when it arrived. Different from a simple reminder — the full decision context is restored.
What email types does Letterbot recognize? +
INVOICE, CONTRACT, SECURITY_ALERT, PRICE_LIST, NEWSLETTER, NOTIFICATION, and others. Classification drives the base priority level and the suggested action shown in the Telegram message.
What is obligation tracking? +
Letterbot detects commitment phrases in email bodies: "will send by Friday", "confirm by Monday", "I will call tomorrow". These are tracked and surfaced in the weekly digest, showing who promised what — including your own outbound commitments.
What does a Telegram notification look like? +
One email = one message. Structure: priority emoji + email type · sender name · subject · 2–3 line summary · suggested action · attachment note if any · priority buttons · snooze options. Tapping a priority button immediately updates the stored priority and trains the model.
Installation & setup
How do I install Letterbot? +
1) Download the ZIP from GitHub releases. 2) Unzip to any folder (e.g. C:\letterbot). 3) Fill in accounts.yaml with your IMAP credentials and Telegram bot token. 4) Run letterbot.bat. Total time: ~10 minutes. Full instructions in the README inside the archive.
Do I need Python installed? +
For the bundled Windows build, ideally no — the .bat launcher handles the Python environment. For advanced users or non-Windows, Python 3.10+ is required and pip install -r requirements.txt installs dependencies.
How do I create a Telegram bot? +
Open Telegram → search @BotFather → send /newbot → follow the prompts. You receive a bot token. Set it in accounts.yaml. Takes about 2 minutes. No Telegram Premium required.
How do I run the health check? +
Run python -m mailbot_v26 doctor in the project folder. It checks: IMAP connection status per account, Telegram bot delivery, LLM provider reachability, database integrity, and config validation. Color-coded output with specific error messages.
Telegram messages are not arriving — what do I check? +
Check: bot token in config is correct, chat_id is a numeric ID (not a username), internet access is available. Run the doctor check: python -m mailbot_v26 doctor. If still stuck, open a GitHub Issue with the doctor output.
