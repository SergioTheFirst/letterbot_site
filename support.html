Why is Letterbot free?
Because the goal was to build a useful tool, not a business. An honest free tool that people actually use is more valuable than a mediocre product with a paywall. The open-source license (AGPL-3.0) ensures this commitment is permanent — not just a marketing promise.
What does a donation actually change?
It buys time. New releases come out faster. The Windows installer gets improved. Documentation gets better. Edge cases in corporate Exchange setups get fixed. The Telegram channel stays active. Without support, the project moves slower.
Specifically: new LLM provider integrations, improved IMAP edge case handling, better setup wizard, expanded FAQ, and architectural improvements planned for v29 all depend on available development time.
Will Letterbot ever have ads or a paid tier?
No. Ads would destroy the trust of an audience that chose a local tool precisely because they distrust data collection. A paid tier would contradict the core positioning. The only possible future monetization is optional managed hosting for non-technical users — a separate product, not a limitation on the self-hosted version.
What if I can't donate?
That is completely fine — and expected. The tool is free unconditionally. Non-financial help matters too: star the GitHub repository (improves discovery), report bugs (improves quality), write about Letterbot in your developer community, or share it with someone who would benefit.
