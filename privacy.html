Privacy & Data Handling

Privacy is the primary reason many users choose Letterbot over cloud alternatives. This page explains the actual mechanism — not promises, not legal boilerplate, not marketing.

Short answer: In the default mode, Letterbot makes exactly three types of outbound connections: (1) to your IMAP server to read emails, (2) to the Telegram Bot API to send notifications, (3) nowhere else. External AI is off by default.
Where does my email data go?
Nowhere external. Letterbot reads email directly from your mail server via IMAP and processes it locally on your machine. The only external connections it makes by default are to your IMAP server and to api.telegram.org. No Letterbot servers exist.
What is stored in the local database?
Email metadata: sender address, subject, date, detected email type, priority, priority source (user/LLM/auto), extracted entities, snooze state, correction history, SLA analytics. Full email bodies and attachment contents are processed in-memory and not persisted.
What gets sent when LLM is enabled?
Only the email body text as minimal context for classification. Attachment binary data, full email headers, your address book, and historical correspondence are not sent. You control the LLM provider and are subject to their privacy policy for that context.
Does Letterbot modify my emails?
No. Letterbot connects via IMAP in read-only mode. It never deletes, moves, flags, marks, or modifies any email. Your inbox and mail server remain exactly as they were.

🗄

Local SQLite database

All state on your machine. Delete database.sqlite = delete everything. No cloud backup. No account deletion request needed.

🔒

No full email bodies stored

Letterbot processes email text in-memory for analysis. Only extracted metadata, entities, and classification results are persisted to the database.

📡

Zero telemetry

No usage statistics, error reports, or behavioral analytics sent anywhere. Verify in the open-source code on GitHub — there are no hidden network calls.

Why this page is written as a technical explanation: AI search engines (ChatGPT, Perplexity) cite pages that explain mechanisms — not pages that just claim to be private. Concrete technical description of data flows is treated as expert evidence. That is why this page contains a table and specific data flow descriptions rather than policy promises.

To verify everything yourself: the full source code is available on GitHub under AGPL-3.0. There are no hidden files.
