Pricing and free usage

Last updated: March 2026

Direct answer: LetterBot is positioned as a free, open-source, self-hosted tool. The point is not to lock you into another monthly mail subscription. The project is sustained through voluntary support.

What you get for free

  • Source code
  • Self-hosted deployment
  • Telegram workflow
  • Local dashboard
  • Core triage model

How the project stays alive

  • User donations
  • Community support
  • Open-source credibility and trust
