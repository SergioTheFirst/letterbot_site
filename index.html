// what is it

What is Letterbot?

Letterbot is a free, self-hosted AI email filter for Windows that connects to your IMAP mailbox, analyzes incoming emails, and sends concise Telegram notifications — only for messages that require your attention.

🧠

AI prioritization

Classifies every email as 🔴 Urgent / 🟡 Important / 🔵 Low. Extracts the action you need to take. Learns from your corrections.

📲

Telegram as UI

One email → one message. No email client to check. Priority buttons and snooze right in Telegram chat. Works on any device with Telegram installed.

🔒

Privacy by design

Letterbot has no servers of its own. Everything runs on your machine. SQLite stores metadata locally. Zero telemetry.

// 3 steps

How Letterbot works

1

Connects to your mailbox

Letterbot connects via IMAP in read-only mode. It does not delete, move, or alter any emails. Supports Yandex, Mail.ru, Gmail, corporate Exchange and any IMAP provider.

2

Analyzes and prioritizes

Extracts sender, subject, attachments, body, obligations. Determines priority and suggested action. Works without external AI — LLM is an optional enhancement.

3

Sends to Telegram

One email → one message with priority, summary and action buttons. You can override priority, snooze, or confirm — all from Telegram. System learns from your feedback.

// full feature set

Everything Letterbot does

📎

Attachment reading

Extracts text from PDF, Word (.docx), Excel (.xlsx) without installing Office. Attachment content is used in priority calculation.

📅

Weekly digest

A weekly summary with invoice totals, contract deadlines, silent-partner risks, and outstanding obligations sent every Monday.

⏰

Snooze with memory

Snooze an email for 2h, tomorrow, or next week. When it returns, it comes back with context — who sent it, what was requested.

📊

Local web UI

Built-in observability cockpit at localhost:8787. Dashboard, email archive, health page, AI decision trace. Read-only, stays local.

🔁

Adaptive learning

Override a priority in Telegram and the system records it as a correction signal. Over time, Letterbot learns your attention patterns.

🛡

Degraded mode

If your LLM provider is unavailable, Letterbot automatically switches to deterministic mode. Basic notifications keep flowing.

🔗

Obligation tracking

Detects commitments ("will send by Friday", "confirm by Monday") in email threads. Surfaces them in the weekly digest.

📡

Explainable AI

Every priority decision comes with a reason code (PRIO_INVOICE, PRIO_DEADLINE_1D, PRIO_FREQ_SPIKE). No black box.

// technical specs

System requirements

  • Windows 10 / Windows 11 (64-bit)
  • Python 3.10+ (or use the bundled .bat)
  • ~1 GB free RAM (tested on Celeron N4020, 3 GB)
  • IMAP access to your mailbox
  • Telegram Bot Token (via @BotFather)

What's inside

  • Python 3.10+, SQLite — no Docker, no Kubernetes
  • IMAP: Yandex, Mail.ru, Gmail, Exchange, any
  • LLM (optional): GigaChat, OpenAI, Cloudflare Workers AI
  • Local web UI: http://127.0.0.1:8787
  • License: AGPL-3.0 (open source)

Frequently asked questions

Direct answers in the first sentence. See all 30+ questions →

What is Letterbot? −
Letterbot is a free, self-hosted AI email filter for Windows. It reads your IMAP inbox, prioritizes messages with AI, and sends only the important ones to Telegram as short, action-ready notifications. Your emails never leave your machine.
Does it require ChatGPT or any paid AI service? +
No. Letterbot runs without any external AI in its default deterministic mode. LLM providers — GigaChat (Sber), OpenAI, Cloudflare Workers AI — are all optional and only activated when you explicitly configure them.
Where does my email data go? +
Nowhere external. Letterbot processes emails locally. Metadata is stored in a SQLite database on your machine. There is no Letterbot cloud server. If you enable an LLM, only minimal context is sent to that provider — never full email bodies or attachments.
Can I connect multiple email accounts? +
Yes. Letterbot supports unlimited IMAP accounts. You can route each account to a separate Telegram chat — work emails to one chat, personal to another, server alerts to a third. This Multi-Inbox Routing feature is unique among free email tools.
Is Letterbot free forever? +
Yes. Letterbot is free, open source (AGPL-3.0), and will remain so. The project is supported by voluntary donations via Boosty. There is no freemium, no feature paywall, no subscription tier.
