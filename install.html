Step-by-step setup

1

Download & unzip

Download the ZIP from GitHub Releases. Unzip to any folder, for example C:\letterbot. No installer. No admin rights needed.

2

Configure

Open accounts.yaml in any text editor. Add your IMAP credentials (host, user, app password) and your Telegram bot token. See the README for provider-specific setup.

3

Run

Double-click letterbot.bat. Letterbot starts polling your inbox. Telegram notifications arrive on the first completed check cycle.

How do I create a Telegram bot?
Open Telegram → search @BotFather → send /newbot → follow prompts. You receive a bot token. Paste it into accounts.yaml. Takes 2 minutes. Free, no Telegram Premium needed.
How do I find my chat_id for Telegram?
Send any message to your new bot, then open https://api.telegram.org/bot<TOKEN>/getUpdates in a browser. Your numeric chat_id appears in the from.id field. This is what goes in the config.
How do I get an app password for Gmail?
Go to Google Account → Security → 2-Step Verification → App passwords. Generate a password for "Mail" on "Windows Computer". Use this password (not your main password) in accounts.yaml.
How do I verify the installation worked?
Run python -m mailbot_v26 doctor in the project folder. It checks every component — IMAP connection, Telegram delivery, database, config — with color-coded results and specific error messages for anything that fails.

System requirements

  • Windows 10 or 11 (64-bit)
  • IMAP access to your mailbox
  • Telegram bot token (from @BotFather)
  • ~200 MB free disk space
  • ~1 GB free RAM (tested: Celeron, 3 GB total)
  • Internet for IMAP sync and Telegram

What is in the ZIP

  • letterbot.bat — one-click launcher
  • accounts.yaml — config template with comments
  • settings.ini — advanced settings
  • doctor.bat — health check tool
  • README with setup guide for all providers
  • Example configs for Yandex, Mail.ru, Gmail
