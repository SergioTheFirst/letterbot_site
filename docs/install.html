Install LetterBot

Direct answer: On Windows, the easiest way to start is the included launcher. It prepares the environment, guides first-run configuration, and starts the local workflow with minimal friction.

Quick start

  1. Download or clone the repository.
  2. Make sure Python 3.10+ is installed.
  3. Run letterbot.bat on Windows, or use Python directly.
  4. Fill the generated config files with IMAP and Telegram settings.
  5. Start the worker and open the local observability dashboard.

PowerShell example

git clone https://github.com/SergioTheFirst/letterbot.git
cd letterbot
.\letterbot.bat

Python example

python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m mailbot_v26 init-config --config-dir .
python -m mailbot_v26.tools.run_stack --config-dir . --no-browser
