## GitHub Pages setup

1. Upload every file from this bundle to the repository root.
2. GitHub → Settings → Pages
3. Source: Deploy from a branch
4. Branch: main
5. Folder: /(root)
6. Save

## Final URL

https://sergiothefirst.github.io/letterbot_site/

## Why root publish is used

- safer for project pages
- simpler relative linking
- fewer broken path problems
- easier GitHub Pages maintenance
