About Letterbot
What is Letterbot? −
Letterbot is a free, self-hosted AI email filter for Windows. It connects to your IMAP mailbox, analyzes incoming emails, determines priority and the suggested action, and sends concise notifications to Telegram. Your emails never leave your computer — there is no Letterbot cloud.
Who is Letterbot for? +
Primarily for people whose inbox has become a task list: freelancers, sole traders, developers, and small businesses with active B2B correspondence. Especially useful for those who value privacy — data stays on your machine. Also a great use case for an old laptop or spare PC you want to put to work.
How is Letterbot different from Gmail AI or email filters? +
Standard filters sort emails by rules. Letterbot translates an email into an action: "pay", "reply", "review contract", "snooze". It delivers that action to Telegram as a short message with priority buttons. The core difference: it is a decision system, not a storage system. And it runs locally — your data does not go to Google or any other cloud.
How is Letterbot different from paid tools like Superhuman or SaneBox? +
Letterbot is self-hosted, free, and open source. Superhuman costs $30/month and is cloud-only. SaneBox costs $7–36/month and also runs in the cloud. Letterbot is the only free tool in the "local + Telegram + multi-inbox routing" intersection. For enterprise SLA guarantees, look at paid alternatives.
Privacy & data
Where does my email data go? +
Nowhere external. In the default mode, Letterbot processes everything locally. Email metadata (sender, subject, date, detected entities) is stored in a SQLite database on your machine. No Letterbot server exists to receive your data.
Does Letterbot require ChatGPT or paid AI services? +
No. The default deterministic mode works without any external AI service. LLM providers — GigaChat (Sber), OpenAI, Cloudflare Workers AI — are optional enhancements. Without them, the system uses rule-based extraction with slightly lower accuracy on unusual texts, but fully operational.
If I enable an LLM, what gets sent to it? +
Only the email's text body (minimal context for classification). Attachments are not sent. You control which LLM provider is used via the config file. The provider you choose handles that data under their own privacy policy.
What is stored in the local SQLite database? +
Metadata: sender email, subject, date, detected email type, priority, priority source, extracted entities, snooze status, and processing analytics. Full email bodies and attachments are not stored in the database.
How do I delete all Letterbot data? +
Delete the project folder, or just the database.sqlite file. There are no cloud backups, no remote storage, nothing to request deletion of — all data is on your machine.
Does Letterbot have telemetry or analytics that phones home? +
No. Letterbot has zero telemetry. The only external connections it makes are: to your IMAP server, to the Telegram Bot API, and (if enabled) to your chosen LLM provider. The source code is open — you can verify this yourself on GitHub.
Technical questions
Can Letterbot run on an old or slow computer? +
Yes — this is one of the best Letterbot use cases. It is tested on an Intel Celeron N4020 (2 cores, 1.1 GHz) with 3 GB RAM. An old laptop or spare desktop PC makes an excellent dedicated local email assistant.
Does Letterbot modify or delete my emails? +
No. Letterbot connects to your mailbox via IMAP in read-only mode. It does not delete, move, mark, or alter any emails. Your inbox remains exactly as it was.
Which email providers are supported? +
Any mailbox with IMAP access: Yandex.Mail, Mail.ru, Gmail (with app password), corporate Exchange / Office 365, Outlook, ProtonMail Bridge, FastMail, and any IMAP-compatible server. If you have an IMAP host and password, it works.
Can I connect multiple email accounts? +
Yes. Multi-Inbox Routing is one of Letterbot's key features. You can connect unlimited mailboxes. Each can be routed to a separate Telegram chat — work email to the work chat, personal to another, server alerts to a dedicated channel.
What happens if the internet goes down? +
Letterbot cannot sync IMAP or deliver Telegram messages without internet. It does not crash — it retries automatically on the next cycle. All local data remains intact.
Is there a local web interface? +
Yes. Letterbot includes a read-only local cockpit at http://127.0.0.1:8787 with a dashboard, email archive, AI decision trace, system health, delivery SLA metrics, and sender relationship analytics. It does not connect to the internet.
Can Letterbot read PDF and Excel attachments? +
Yes. Letterbot extracts text from PDF and Excel (.xlsx) files without requiring Microsoft Office. Attachment content is factored into the priority calculation — an invoice in a PDF attachment can trigger 🔴 Urgent priority.
What is the weekly digest? +
A weekly summary sent every Monday containing: total emails processed, invoices detected, contracts for review, overdue obligations, silent-partner risks (contacts who stopped replying), and pending replies you haven't acted on yet.
What if my LLM provider goes down? +
Letterbot automatically enters DEGRADED_NO_LLM mode and continues sending basic notifications using its deterministic extraction engine. You are notified of the degraded state via Telegram. When the LLM recovers, normal mode resumes automatically.
Features & behavior
How does priority work? How does Letterbot decide what's important? +
Letterbot analyzes sender history, email type (invoice, contract, alert), deadline keywords, attachment type, and frequency signals. The result: 🔴 Urgent (today) / 🟡 Important (next few days) / 🔵 Low. Every decision includes a reason code like PRIO_INVOICE or PRIO_DEADLINE_1D, so you can see why a priority was assigned.
Does Letterbot learn from my corrections? +
Yes. When you override a priority in Telegram, the correction is recorded as a training signal. Over time, Letterbot's priority model adapts to your real behavior — which senders you treat as urgent, which you consistently ignore.
How does snooze with memory work? +
Tap a snooze button in Telegram (2h, tomorrow, next week). At the scheduled time, Letterbot resurfaces the email with context — original sender, subject, what was detected, when it arrived. This is different from a simple reminder: it restores the full decision context.
What email types does Letterbot recognize? +
INVOICE, CONTRACT, SECURITY_ALERT, PRICE_LIST, NEWSLETTER, NOTIFICATION, and several others. Classification is used to determine base priority and the suggested action.
What is obligation tracking? +
Letterbot detects commitment phrases ("will send by Friday", "confirm by Monday", "I'll call you tomorrow") in email bodies. These are tracked and surfaced in the weekly digest so you can see who promised what — and whether you have outstanding commitments yourself.
What does the Telegram notification look like exactly? +
One email = one message. Structure: priority emoji + email type · sender name · subject · 2–3 line summary · suggested action · attachment note (if any) · priority change buttons · snooze options. Tapping a priority button immediately updates the stored priority.
Installation & setup
How do I install Letterbot? +
1) Download the ZIP from GitHub releases. 2) Unzip to a folder (e.g. C:\letterbot). 3) Fill in accounts.yaml with IMAP credentials and Telegram bot token. 4) Run letterbot.bat. Total setup time: ~10 minutes. Full instructions in the README inside the archive.
Do I need to know Python? +
For the bundled Windows build, ideally no — the .bat script handles the environment. However, the project is in active development, so some setup steps may require a command line. This is suited for technically comfortable users.
How do I create a Telegram bot? +
Open Telegram → search @BotFather → send /newbot → follow the prompts. You receive a bot token. Set it in Letterbot config. Takes about 2 minutes. No Telegram premium required.
How do I run the health check? +
Run python -m mailbot_v26 doctor in the project folder. It shows the status of each component: IMAP connections, Telegram bot, LLM provider, database, and configuration. Color-coded results with specific error messages if something is wrong.
Telegram messages aren't arriving. What do I check? +
First: check the bot token in config, verify the chat_id is correct (must be numeric), confirm internet access. Run python -m mailbot_v26 doctor — it shows Telegram status specifically. If still stuck, open an issue on GitHub or email master@letterbot.ru.

Yes, free forever. Letterbot is an independent open-source project, not a startup with investors. There is no freemium model, no "pro version", no locked features. Development is sustained by voluntary donations via Boosty and CloudTips.
How can I support the project? +
Via Boosty or CloudTips — voluntary donation of any amount. Also: star the GitHub repository, report bugs, share with your community, or join the Telegram channel.
Will Letterbot ever become paid? +
No. The project's founding principle is free and open. Even if a managed hosting service is introduced in the future for non-technical users, the self-hosted version will always be free.
