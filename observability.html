Observability

Every decision is traceable. Every metric is visible.

What is the web cockpit?

A local, read-only web dashboard running at http://127.0.0.1:8787. It shows system health, processed emails, AI decision traces, and delivery metrics. It never connects to the internet and never exposes data externally.

Cockpit sections

  • Dashboard — live overview: emails processed, LLM usage, priority distribution, recent events
  • Archive — searchable history with filters by document type, priority, sender, confidence
  • Health — IMAP connection status, LLM provider health, database state, component matrix
  • Events timeline — every system decision in chronological order, fully auditable

SLA metrics

Letterbot tracks delivery performance: delivery_rate, error_rate, p90_latency, salvage_rate. These are real production metrics typically found in SaaS platforms, not hobby projects.

Decision traces

Every priority decision has auditable reason codes. You can see exactly why an email was classified as 🔴 Urgent: which facts were extracted, what weights were applied, what signals triggered.
