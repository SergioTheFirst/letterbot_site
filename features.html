What does Letterbot do?

Each feature is described as a direct answer to "what does it do" — not as a marketing claim. If a feature doesn't exist, it's not listed.

How does Letterbot prioritize emails?
Letterbot analyzes sender history, email type, deadline keywords in subject and body, attachment type, and frequency signals from the same sender. Result: 🔴 Urgent (action today) / 🟡 Important (next few days) / 🔵 Low. Every decision includes a reason code — PRIO_INVOICE, PRIO_DEADLINE_1D, PRIO_FREQ_SPIKE_3X — so you can see exactly why a priority was assigned. Not a black box.
How does Multi-Inbox Routing work?
You define multiple IMAP accounts in accounts.yaml, each with a target Telegram chat_id. Letterbot routes each account's notifications to its designated chat. Work emails go to the work group chat, personal emails to your private chat, server alerts to a dedicated channel. No limit on the number of accounts.
How does snooze with memory work?
Tap a snooze button in Telegram — 2 hours, tomorrow, next week. Letterbot persists the snooze in the local database with a wakeup timestamp. At the scheduled time, it resurfaces the email with full context: sender, subject, detected type, suggested action, and when it originally arrived. The decision context is fully restored, not just a bare reminder.
Does Letterbot learn from corrections?
Yes. When you tap a priority button in Telegram to override the system's decision, the correction is recorded as a training signal associated with that sender and email type. Over time, the priority model adapts to your real behavior — which senders you consistently treat as urgent, which you consistently downgrade.
What does the weekly digest contain?
Sent every Monday: total emails processed in the past week, invoices detected with amounts, contracts that arrived for review, overdue obligations (commitments that passed their stated deadline), silent-partner risks (contacts you haven't heard from in longer than normal), and pending replies you haven't acted on.
How does Letterbot read PDF and Excel attachments?
Letterbot uses open-source text extraction libraries to read PDF and .xlsx files without requiring Microsoft Office. The extracted text is used during priority calculation — an invoice amount in a PDF can trigger the PRIO_INVOICE reason code, an Excel spreadsheet containing contract terms can increase priority to 🟡 Important.
What does the local web cockpit show?
Available at http://127.0.0.1:8787. The cockpit includes: a system dashboard with current health status, IMAP connection state per account, Telegram delivery metrics (p90 latency, delivery rate, error rate, salvage rate), processed email archive with full decision trace and reason codes, sender relationship analytics, and a system health page with per-component status. Read-only. Does not connect to the internet.
What is obligation tracking?
Letterbot scans email bodies for commitment phrases: "will send by Friday", "confirm by Monday", "I'll call you tomorrow", "payment due April 15". Detected commitments are stored with their deadline date. Both incoming obligations (what others promised you) and outgoing ones (what you promised) are tracked and surfaced in the weekly digest.

How does Letterbot handle failures?

⚡

Degraded mode (DEGRADED_NO_LLM)

When an LLM provider is unavailable, Letterbot automatically switches to deterministic mode. Basic notifications using rule-based extraction continue. You receive a Telegram notification about the degraded state. Normal mode resumes automatically when the LLM recovers.

🔁

Telegram retry with backoff

If a Telegram API call fails, Letterbot retries with exponential backoff. Emails processed during an outage are queued locally and delivered when connectivity is restored — no silent message loss.

🛡

UIDVALIDITY / IMAP resync

Letterbot tracks IMAP UIDVALIDITY per account. When the IMAP server signals a UID reset (e.g. after mailbox migration), Letterbot automatically resyncs state to prevent duplicate deliveries or missed messages.
