Install and run LetterBot

Answer: On Windows, run letterbot.bat from the repo folder. It creates a local virtual environment, generates config files, and starts the worker + web console.

Last updated: 2026-03-11

Quick start on Windows

  1. Download the repository as ZIP (or clone it).
  2. Ensure you have Python 3.10+ installed.
  3. Double-click letterbot.bat.
  4. On first run, it generates accounts.ini and opens it for editing.
  5. Fill in IMAP credentials + Telegram bot settings, save, then run letterbot.bat again.
# Clone (PowerShell)
git clone https://github.com/SergioTheFirst/letterbot.git
cd letterbot
.\letterbot.bat

Manual run with Python

Use this if you don’t want the Windows launcher.

# Create venv (example)
python -m venv .venv
# Activate (Windows PowerShell)
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# Initialize config (creates accounts.ini / settings.ini)
python -m mailbot_v26 init-config --config-dir .

# Run stack (worker + web console)
python -m mailbot_v26.tools.run_stack --config-dir . --no-browser

Open the observability console

When running, the web console is available locally (look for the printed URL in logs). Use it to inspect decision traces, routing, and system health.

Troubleshooting

  • Port already in use: change the web port in config, then restart.
  • No Telegram messages: verify bot token and chat ID.
  • IMAP auth errors: verify host/port/TLS and credentials.
