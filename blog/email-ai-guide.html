How AI email filters work

A technical explanation of email AI prioritization — signal extraction, LLM classification, learning from corrections — written for technically comfortable non-engineers.

What does "AI email prioritization" actually mean?
It means applying a series of signal extraction and classification steps to determine which emails deserve your attention now versus later. The word "AI" in this context covers a spectrum: from simple keyword matching (deterministic) to large language model classification (LLM). Most production systems use both, with LLM as an enhancement layer over a deterministic core.
What signals does an email AI extract?
Modern email AI systems (including Letterbot) extract signals at multiple layers:
  • Sender signals: history with this sender, frequency baseline (is this unusually high or low?), relationship score, last interaction date
  • Content signals: email type classification (invoice, contract, security alert, newsletter), deadline keywords, monetary amounts, named entities
  • Structural signals: attachment type and size, reply chain depth, CC/BCC patterns, subject line structure
  • Behavioral signals: how the user has historically responded to emails from this sender and of this type — the most powerful signal over time
When is an LLM used, and when is deterministic logic enough?
Deterministic logic (keyword matching, regex, rule engines) handles well-structured cases reliably and cheaply: invoice emails with standard formats, security alerts with known patterns, newsletters with unsubscribe links. LLMs add value for ambiguous cases: an email that is technically a price list but is actually a negotiation opener, or a brief email from a new contact that requires contextual understanding to classify.
Letterbot's design: the deterministic engine is the foundation, always available. LLM classification is an optional enhancement layer. If the LLM is unavailable, the system enters DEGRADED_NO_LLM mode and continues operating on deterministic signals alone — useful delivery rate, lower accuracy on edge cases.
How do email AI systems learn from user behavior?
Learning happens through correction signals. When a user overrides a system decision — marking an "Important" email as "Low" or vice versa — the system records the correction associated with the sender, email type, and context signals present at that time. Over many corrections, the model adjusts its weights for that sender and type. This is not deep learning in the machine learning sense — it is weighted rule adjustment based on observed user preferences.
In Letterbot: priority overrides via Telegram buttons are recorded in the local SQLite database as correction signals. The priority engine uses these to adjust sender-level scores on subsequent emails. The full correction history is visible in the local observability cockpit.

The key insight for users

The best email AI system is not the one with the most sophisticated model — it is the one that learns most accurately from your corrections. A local system that you correct consistently will outperform a cloud system with more data but no feedback loop from you specifically.
