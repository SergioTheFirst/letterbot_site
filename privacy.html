Privacy & Data Handling

Privacy is the primary reason people choose Letterbot over cloud alternatives. This page is written as a technical explanation of mechanisms — not marketing promises, not legal boilerplate.

TL;DR: In the default mode, Letterbot makes exactly three types of external connections: (1) to your IMAP server to read emails, (2) to the Telegram Bot API to send notifications, (3) nowhere else. All processing, storage, and analytics are local on your machine. External LLMs are off by default.
// default mode (no LLM)

What stays on your machine

🗄

Local SQLite database

All email metadata, priorities, events, snooze state, correction history, analytics, and relationship scores are stored in database.sqlite on your machine. No cloud backup. Delete the file = delete everything.

🔒

IMAP — read-only

Letterbot connects to your mail server directly via IMAP in read-only mode. It does not delete, move, flag, or modify emails. The connection is between your PC and your mail server only — Letterbot is not a relay.

📡

Telegram Bot API

Notifications are sent via the official Telegram Bot API (api.telegram.org). Only the formatted notification text is sent — no full email bodies, no attachments, no raw sender data beyond what appears in the message itself.

What gets sent when LLM is enabled

All external AI providers are disabled by default. You explicitly activate one in the config file.

🤖

GigaChat (Sber) — Russian LLM

When enabled: the email's text body is sent to GigaChat for classification. Processed under Sber's data policy. Preferred choice for Russian businesses that want data to stay within Russian jurisdiction.

Disabled by default · enable with llm_provider: gigachat
☁️

OpenAI / Cloudflare Workers AI

When enabled: minimal text context sent to the configured provider for classification. Processed under their respective policies. Useful for highest accuracy on English-language emails.

Disabled by default · system runs in DEGRADED_NO_LLM without any config

What is explicitly NOT stored

📧

Full email bodies

Full text of emails is processed in-memory and not persisted to the database. Only extracted metadata, entities, and classification results are stored.

📎

Attachments

Attachment contents are extracted in-memory for analysis, then discarded. Attachment text is never saved to the database or sent to external services.

📊

Usage analytics / telemetry

Zero telemetry. Letterbot does not phone home with usage statistics, error reports, or any other data about how you use it. Verify in the open-source code.
