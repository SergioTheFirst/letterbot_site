Install LetterBot

Last updated: March 2026

Direct answer: Clone the repository, install Python dependencies, generate the config, connect IMAP and Telegram, then run the Windows launcher or start the Python stack directly.

Quick start

git clone https://github.com/SergioTheFirst/letterbot.git
cd letterbot
python -m pip install -r requirements.txt
python -m mailbot_v26 init-config --config-dir mailbot_v26/config

Run it

# Windows
letterbot.bat

# Or directly
python -m mailbot_v26 --config-dir mailbot_v26/config

Python 3.10+

The launcher and repo guidance assume Python 3.10 or newer.

IMAP access

LetterBot needs access to the inboxes you want it to watch.

Telegram bot token

Create one via BotFather and connect the target chats.
