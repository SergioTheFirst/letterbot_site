Security

Direct answer: LetterBot is most secure when treated like a local operational service: protect the host, keep secrets in configuration files under your control, restrict dashboard exposure, and report vulnerabilities privately.

Security principles

  • Least exposure: bind the dashboard locally unless you intentionally publish it.
  • Secret hygiene: keep Telegram tokens and mailbox credentials private and rotate them if exposed.
  • Operational visibility: use logs and the dashboard to verify behavior after changes.

Responsible disclosure

If you discover a security issue, contact the maintainer privately before public disclosure. Include steps to reproduce, impact, and environment details when possible.
