What was added, fixed, or changed in each Letterbot release. Current version: v.

Current v28.0.0 · March 2026
Download →

v28 — Architecture hardening & source-of-truth audit

  • Startup assertion: knowledge_db.path == storage.db_path — prevents silent snooze divergence
  • IMAP UID loop guard for Yandex RFC3501 edge case
  • Database lock fix: sqlite3.connect(timeout=10) in emitter
  • Analytics OperationalError catch in top_sender_relationship_profiles()
  • Visibility change handler added to cockpit.html and health.html
  • Config hot-reload improvements
  • _provider_has_real_credentials moved to StartupHealthChecker
Previous v27.1.0 · February 2026

v27.1 — Priority buttons & snooze fixes

  • Priority button callbacks now correctly update emails.priority and emails.priority_source
  • Snooze write path consolidated — all writes go through single _save_snooze function
  • Snooze read path (storage.list_due_snoozes()) confirmed to use same DB path as writer
  • Web UI priority reads confirmed to go through emails.priority column only
  • Web cockpit page layout improvements
v27.0 January 2026

v27 — Web cockpit beta

  • Local observability web cockpit launched at localhost:8787
  • Dashboard, email archive, health page, AI decision trace
  • Delivery SLA metrics: p90 latency, delivery rate, error rate, salvage rate
  • Relationship analytics: sender trust scores, anomaly detection
  • Insight/narrative layer for weekly digest
v26 2025

v26 — Multi-account, adaptive learning, obligation tracking

  • Multi-Inbox Routing: unlimited IMAP accounts, per-account Telegram chat routing
  • Adaptive priority learning from Telegram button corrections
  • Obligation tracking: detects commitment phrases, surfaces in weekly digest
  • Snooze with context memory
  • GigaChat (Sber) LLM provider added
  • DEGRADED_NO_LLM mode with automatic recovery
  • Weekly digest with financial and obligation summary
